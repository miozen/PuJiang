# V1 普通父位置子女排行调整切片准备

> 用户已批准按 [D-037](DECISIONS.md#d-037--普通子女排行首批范围) 实施普通单父位置实际排行隔离切片，实际进度见 [接力](HANDOFF.md)。其余规则以 D-029、D-031 及四份 V1 契约为准；按 D-033 不做旧数据兼容或迁移。

## 已确认规则

1. 编修契约 §3.4、§4.7 及领域契约 §11：实际子女排行归属于对应父子挂接位置，男、女各自计算长幼，画布男在前女在后；手工排序只在同一父位置的同一性别组内改变长幼。不同父位置互不影响，操作必须使用有效的父及子 PlacementId。
2. 编修契约 §3.4、领域契约 §11.6 和 D-004：旧谱原文明确记载的历史行第与当前录入人物计算出的实际排行分别保存，不因新增、性别变更或重排自动改写。当前只有两名儿子时，旧谱记载“三子”的原文仍应保留；不得以当前人数填造缺失人物。
3. 领域契约 §11.3–11.4：新增子女进入对应性别组末尾；性别变更后进入新组末尾并重算，允许后续在同组中手动调整。用户已确认不同 Lineage 不共享事实；横向图与吊线图共用同一排行，不能按 ViewMode 或旧 Chart 各存业务排行。
4. D-029 及画布契约 §8：普通编辑以操作完成为提交点自动保存，走统一业务 Command、校验和事务；失败保留输入及原因，不能要求完成一次调整后再按统一保存按钮。排序只修改目标父位置下的相关排行，不改变人物身份、亲属关系、后代承接、世代、历史原文及配偶排序。
5. 普通新增子女和兄弟姐妹的生母按 D-030/D-031/D-035 处理；对现有同胞重排不能改写生母。保留三栏工作台、现有焦点和已验收交互；仅使用独立虚构测试库，不访问真实数据库，不做旧数据兼容、迁移或转换。
6. 用户确认首批实际排行称谓显示在右侧人物资料中，保留画布姓名框和布局；此项与旧谱历史行第无关，见 D-037。
7. 用户确认首批同时支持画布拖动和右键“上移／下移”，操作完成后自动保存，见 D-037；两种入口使用同一排行规则与业务提交机制。

## 首批建议与待确认事项

建议首批限定当前 Lineage 的普通、单父位置、性别明确且顺序完整的同胞组。用户确认复用画布人物拖动并保留右键上移/下移；仅在同组内移动，越过性别组或父位置不提交并清晰提示。拖放或上移/下移完成即自动提交；失败保持原有顺序并保留用户可继续处理的意图。具体拖放反馈和边界提示可按既有交互细化，不改变已确认的性别分组规则。

待确认：

1. **异常处理边界：** 未知性别、位置缺失/重复、组成员不完整及父位置失效时拒绝调整并保留事实；本批不实现专门修复入口，不静默补齐。多位置、嗣继、祧继和无父母兄妹组不在首批范围。

## 最小实施分解（建议）

1. 锁定上述首批交互与异常范围；历史行第独立录入、修改及显示按用户确认留待后续。如涉及额外未确认规则，先协调，不自行推断。
2. 在 Application 定义针对 Lineage、父位置、源/目标子位置和同胞组快照的统一排序 Command；幂等操作标识、完整组及性别校验、位置更新和回执须在隔离库事务内一致。具体快照/版本机制属于待实施设计，必须覆盖新增、性别变化、位置变化与陈旧操作。
3. 投影按位置顺序计算性别组内实际排行；不将实际排行解释或保存为历史行第。渲染只展示结果，不将坐标当事实。
4. 沿用工作台拖动、右键和焦点行为，操作完成自动保存；处理中禁止相互冲突的编辑，已提交但刷新失败要如实报告，失败保留用户输入。实现后进行隔离数据库和 WPF 验证，再请用户验收。

| 场景 | 验收条件 |
|---|---|
| 同性别组调整 | 两名或更多儿子/女儿分别调整，画布顺序和右侧对应组的“长子、次子、长女”等实际排行称谓一致；另一性别组及当前 Lineage 其他父位置不变，姓名框和布局保留。 |
| 组边界 | 男在女前，不能通过拖动或按钮将人物移入另一性别组；不改变性别。 |
| 母亲不同 | 同一父位置下已记录不同生母的子女，重排不更改任何母子关系或主动清空状态；不以配偶顺序分组推断子女排行。 |
| 人物与后代 | 人物、父子关系、PersonId、PlacementId、子树承接和世代保持；分支随人物重排而显示，焦点尽量保持且不误触发姓名编辑。 |
| 历史行第 | 用户确认首批不接入；标记独立字段及录入未实现，不能将实际排行写作历史原文，也不能宣称已验证历史字段保护。 |
| 自动保存和失败 | 完成拖动/上移/下移后不需要额外统一保存；注入写入失败与取消不产生部分排序或回执，用户能保留意图并明确看到结果；提交成功但刷新失败准确提示。 |
| 冲突及重试 | 同胞组新增、性别或位置变化后旧操作拒绝；相同 OperationId 重放不重复调整，不同输入复用同一标识拒绝；不猜测缺失、重复或未知性别的次序。 |
| 隔离与重读 | 不同父位置和不同 Lineage 互不影响；隔离文件库及工作台关闭重开后顺序一致；Person/Relationship、配偶顺序不变。跨整个应用重开需独立样本重开能力，不能用同进程重开代替。 |
| 回归及边界 | 保留已有测试和三栏画布；验证名字输入、世代自动顺排、母亲保护、配偶拖动、焦点及相关 UI；不声称吊线图或复杂关系已实现。 |
