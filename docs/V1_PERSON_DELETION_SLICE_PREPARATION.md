## 契约协调与首批范围

用户确认的 [D-038](DECISIONS.md#d-038--v1-人物删除准备中的用户方向) 替代此前普通主线“单独删除人物”入口：删除从当前选定位置起的整条分支及相关配偶，先列影响并确认；需要保留的子女及后代先拆支。系统总体架构 §6.4、画布工作台 §9.2–9.3、编修操作 §4.3、§4.6 和人物关系领域 §13 中相应表述已定向协调；拆支保留生父母事实，位置删除不等于抹去被引用的人物身份，原有范围外引用保护和复杂关系边界不变。

- 拆支解除普通子女位置的上级连接，保留人物、后代、生父母事实；不自动挂接或推断关系。
- 删除预览列出位置分支、配偶、因业务引用留存的档案及待自动清理档案；取消不写入。仅对本次受影响且已无位置、亲属关系、婚配等必要业务引用的人物执行清理，不全谱扫描。
- 单独删除配偶保留子女：仍在原父位置下的子女原生母留空，后续首配偶按 D-030 补录；已拆支子女原生母事实保留。其他分支不被连带删除。
- 拆支成为首节点后可在右侧输入新人物作为生父母；不按姓名自动合并，未更改的一方保留；资料更新与清理同事务。
- 统一 Command 处理预览快照、重复提交和失败回滚；回执不是亲属事实。仅新建隔离库使用本次映射，不迁移旧样本。
- 不包含复杂多位置、嗣继、祧继、挂接或撤销恢复；首页人物档案统计与画布可见节点不必相同，仍被关系引用的无位置档案不可误删。

## 首批任务及验收矩阵

| 场景 | 验收要求 |
| --- | --- |
| 先拆支 | 子女及后代成为同谱独立分支，身份、世代及原生父母关系保留，重开一致。 |
| 整支删除 | 明确展示受影响人物、配偶、留存及清理；确认后删除所选分支，已拆支及无关分支保留。 |
| 配偶删除 | 保留子女；附原父位置的生母留空并依 D-030 补录，已拆支子女原生母保留。 |
| 首节点父母 | 显式输入新父母并保存，不按姓名合并；未改一方保留，失败不产生半套事实。 |
| 引用与清理 | 被合法关系或位置引用的人物保留，解除最后必要引用后仅清理本次受影响对象。 |
| 事务与并发 | 故障完整回滚；旧快照拒绝、重复操作不重复创建或删除；回执不阻挡已授权删除。 |
| 空画布及隔离 | 已无位置但仍有被引用档案时可再次录入首节点；不影响其他 Lineage，不操作真实库。 |
| 界面与重开 | 现有工作台保留；取消确认不写入，关闭重开后结构和生父母资料一致；用户实际操作另行验收。 |

自动化与人工验收必须分别报告；不将上述目标直接视为通过。复杂关系和恢复删除数据未在本批确认或实施。
