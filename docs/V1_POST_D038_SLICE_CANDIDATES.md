# D-038 后 V1 隔离切片候选

本轮仅整理候选和准备条件，不构成实施批准。保留现有 WPF 工作台，只使用独立虚构样本，不访问真实数据库；按 D-033 项目完成前不做旧数据兼容或迁移。历史行第依用户决定暂缓。

## 当前基线与契约依据

D-038 的普通单位置拆支、整支删除、单独删除配偶、受引用父母身份保留及首节点父母资料修改，已获本次隔离样本用户验收，范围和实际验证见[接力](HANDOFF.md)。拆支不是挂接；右侧录入新父母资料也不等于已将根位置挂到另一个父位置。复杂多位置、嗣继、祧继、完整挂接及撤销未因此实施。

画布契约 §9.2 与编修契约 §4.3 区分拆支和挂接：前者解除位置上级连接并保留原父母事实，后者需要明确来源和目标 PlacementId 及挂接方式。画布契约要求显式选择“迁移本人及后代”“挂接为嗣（继）子”“挂接为祧子”；编修契约另以生子、嗣（继）子、祧子概括关系语义。实施任何入口前应逐项核对两种表述的对应关系与领域契约，不能自行把它们当作完全等价。普通操作限当前 Lineage；不能把跨谱合并当成普通挂接。

## 建议

建议下一步先**准备普通独立分支挂接**：它紧邻已验收的拆支，能进一步处理拆出后如何安排分支，但现有契约术语和父母、世代、排行等影响仍需逐项协调。此处只建议开展契约与现状核对，不决定业务规则、具体首批实现或交互，也不构成实施授权。若用户优先处理排行异常或普通关系纠错，可改选对应候选。
