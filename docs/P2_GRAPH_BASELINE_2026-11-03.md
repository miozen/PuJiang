## 环境与方法

- Windows 10 IoT 企业版 LTSC 10.0.19044，64 位；Intel Core i7-8700 3.20 GHz，6 核 12 线程；物理内存 17,128,722,432 字节；.NET SDK 10.0.403、测试运行时 .NET 10.0.14、Release x64。存储介质、显示缩放及后台负载未记录。
- 基于 `7bae42b` 的本轮图形实现，独立 GUID 临时 SQLite 库，固定虚构样本为 1,000 人、1,023 条关系（989 生物、30 养父母、4 失考）；初始有 41 个图形根节点。测量前后核对人数、关系数和全库代数；未访问正式数据库。
- 命令：`dotnet test PuJiang.Tests/PuJiang.Tests.csproj --configuration Release --no-build --no-restore --filter FullyQualifiedName~Thousand_person_target_lineage_graph_baseline --logger "console;verbosity=detailed"`。独立运行，测试 1/1 通过。
- 3 个独立子进程各测一次首次打开；第一个子进程另外测量 20 次重复打开、姓名定位、ID 定位和根节点展开。主窗口及族谱已初始化，且已读图快照后计时；不包含进程启动或系统冷缓存。打开含获取快照、创建及显示树形窗口、切换至图形、布局到 Dispatcher ApplicationIdle；不证明物理帧呈现。
- 每次定位先清空图形展开状态和查询，再一次性输入完整姓名或 ID、选择目标、触发定位，测到布局及 ApplicationIdle；不含逐字键入、鼠标选择或人工反应。目标为成员 0500。展开先折叠全部图形节点，再展开根人物的 3 个直属子节点；计时至布局及 ApplicationIdle。当前图形为显示节点全量创建 WPF 控件，并非按视口虚拟化。
