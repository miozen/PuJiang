## 当前基线

- 普通单父位置的新增兄弟姐妹已按 D-035 实施，用户对本次隔离样本反馈“验收符合预期”；该反馈不代表复杂多位置或承嗣、祧继已完成。
- D-034 可把**已记录明确世代的已有关系**显示成跨代连线；人工样本中的跨代世代是事先准备的虚构数据，不代表 V1 已有普通子女人工编辑世代入口。
- 项目完成前按 D-033 不设计旧数据/旧模型兼容、迁移或转换；以下候选只使用隔离虚构数据，保留现有 WPF 工作台、交互和测试，不访问真实数据库。

## 共同约束与风险

- 所有持久化操作通过统一 Application Command 和事务，保持失败草稿、PersonId + PlacementId 焦点和现有工作台交互；自动化、人工验收和远端 CI 分别报告。
- D-035 来源生母保护当前比较提交时事实快照，不能检测生母 A→B→A 的往返变化；此限制需在涉及并发或版本守卫的后续方案中明确，不能称为完整历史版本保护。
- D-004 中“主动更正”的用户明确决定仍有效；领域契约禁止某些操作自动覆盖显式世代。准备世代切片时须检查具体操作范围，若存在真正冲突，提出定向协调并等待确认，不以旧实现或新契约的概括句单独覆盖另一方。

## 建议下一动作

优先**准备普通人物显式世代录入与跨代显示切片**：它能让用户通过正常工作台录入用于跨代显示的明确世代；先核对主动更正及后代规则，再确定范围和验收矩阵。隔离跨应用重开、子女排行调整可独立排序；本轮不实施任何候选。
