# V1 普通生子位置新增兄弟姐妹切片准备

> 状态：用户已批准 D-035 普通单父位置隔离实施；本文件下方保留准备阶段的设计与验收建议，实际实现及验证见[接力](HANDOFF.md)。权威决策见 [D-035](DECISIONS.md#d-035--普通生子位置新增兄弟姐妹的生母)。

## 已确认依据与本切片建议边界

- 画布工作台契约 §6.5、编修契约 §1.4 和 §4.1：根据当前选中的 Placement 确定所属父位置；普通生子位置在该父位置下新增。独立根无上级父位置时不执行此操作。不得仅凭 PersonId 或猜测关系选择父位置。
- 画布契约 §6.5：不修改已有兄弟姐妹父母关系，不复制特殊身份或自动在其他位置重复创建；保存后按目标父位置下男女分组和排行显示。统一命令及事务一致性由系统架构契约 §6 约束。
- D-034：真实人物姓名必填，空白不保存、取消不创建；D-029：普通编辑按确认提交点自动保存，失败保留草稿；D-030：普通主线新人物默认男性；D-031：配偶排序归属于当前 Lineage，不由画布坐标或数据库自然顺序确定。
- 建议首批仅覆盖当前人物和父人物位置关系明确、已存普通生父事实、属于同一 Lineage 且父人物可按当前单位置模型处理的场景。嗣子/祧子位置、多位置、缺父、复杂父母及添加独立人物均不因此获准实施。保留现有工作台与测试，仅用独立虚构数据；按 D-033 不做旧数据或旧模型兼容、迁移及转换。

## 生母规则与契约协调

| 依据 | 现有表述 | 对本切片的意义 |
|---|---|---|
| 画布交互 §6.5 | 已按 D-035 修订：被选人物已有生母时新人物默认沿用；未记录时新人物暂不记录。 | 被选人物生母不因父亲配偶排序变化而被替代。 |
| D-030、D-031 | 普通新增子女无配偶可先不记录生母；有配偶取当前 Lineage 第一位有效夫妻配偶；主动清空保护、首配偶限定补录及已有生母不被排序改写。 | 这些规则针对普通新增子女已由用户明确；能否直接适用于兄弟姐妹须结合 §6.5 与其他条款协调。 |
| 画布交互 §16、系统架构 §15.2 | 概括提及“兄弟姐妹继承已知父母关系”。 | 关于生母的具体理解已由 D-035 澄清。 |

例：选中人物生母为乙配偶，而父亲当前第一位有效配偶为甲，新人物默认乙；被选人物没有生母时，新人物暂不记录。后续新增父亲首配偶时新人物按 D-030 补录；被选人物主动清空的生母保持清空。D-030/D-031 对普通新增子女的规则保留。

## 父位置、草稿与版本：现状和技术建议

|---|---|---|

| 命令及事务 | [AddChild](../PuJiang.V1.Application/ChildApplication.cs)当前只接收目标父身份、父位置和配偶顺序版本，并按父亲第一配偶选生母；[存储](../PuJiang.V1.Persistence/IsolatedChildStore.cs)同事务保存人物、关系、位置及回执。 | 不能原样调用该命令而违反 D-035；可复用事务和位置校验，须在同一事务校验来源人物、位置及其生母快照并按确认规则保存。具体命令形态待批准后确定，不以 UI 缓存替代业务校验。 |
| 排序版本 | 子女草稿记录 `_draftSpouseRevision`；提交时比较目标父人物配偶顺序版本；异常/角色不一致拒绝，失效后保留姓名并提供重新绑定。[测试](../PuJiang.Tests/V1ChildSliceTests.cs)及 [窗口测试](../PuJiang.Tests/V1FirstRootWindowTests.cs)覆盖普通子女相关路径。 | 配偶排序版本与被选人物生母事实是不同上下文，前者不能替代后者。生母或来源位置发生变化时建议拒绝过期提交并保留输入；配偶排序变化是否需要使本操作失效，应根据最终命令的实际依赖设计，不得因排序更改新人物的默认生母。排行数据须在事务中校验。 |
| 切换及失败 | 现有工作台切谱遇未保存输入提示保存，拒绝切换或失败时保留；保存结果不确定时保留操作 ID；输入期间禁止直接换选人物。 | 保留现有交互，新增入口使用相同草稿和不确定结果保护；重复提交同一操作不能重复创建，不同内容不能复用同一操作 ID。提交成功但刷新失败应如实提示已保存，不能重复创建。 |

## 建议验收矩阵（未执行）

| 场景 | 验收条件 |
|---|---|
| 普通新增 | 选中已有普通子女，通过新增兄弟姐妹录入姓名；新人物、普通生父关系、位置和排行一次提交，焦点为新 PersonId + PlacementId，画布展示与重读一致。 |
| 生母协调 | 被选人物生母乙、当前第一配偶甲时，新人物默认乙；被选人物未记录生母时，新人物暂不记录。随后新增首配偶，符合条件的新人物按 D-030 补录；主动清空过的被选人物仍保持清空。 |
