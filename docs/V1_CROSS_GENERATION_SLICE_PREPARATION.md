# V1 跨代直接连线隔离切片准备

> 状态：用户已批准最小隔离实施；明确事实的跨代显示及姓名保护已接入，验证与限制见[接力](HANDOFF.md)。本文件保留实施前的现状、任务与验收建议，不能据此宣称复杂关系已实现。权威决策见 [D-026、D-030、D-033、D-034](DECISIONS.md)。

## 已确认的边界

- 首节点、子女、兄弟姐妹和配偶等为普通真实人物录入，须填写姓名后保存；不因姓名缺失判断人物存在与否。主线既有姓氏不能代替待输入的名字；输入取消或空白不能持久化人物及相关关系、位置，草稿失败仍按 D-029 保留。
- 连接性空节点不是人物；跨代直接连接不创建中间 Person、Placement、关系事实或统计项，路径拐点仅为显示几何。人物修改姓名保留身份；显式世代和已确认亲属关系不由布局改写。
- 保留现有三栏工作台和已验收交互、D-030 生母与 D-031 排序；Lineage 内业务隔离，统一命令及事务约束不变。同谱 ViewMode 共用事实，不将尚未实现的吊线图纳入本切片。
- 项目完成前不做旧数据或旧模型兼容、迁移、转换；仅使用全新隔离虚构数据，不访问真实数据库。保留当前未提交工作和既有测试，不因此删除任何数据或测试。

## 现状与最小技术方向

旧 [HorizontalLineageLayout](../ZupuPaiBan/Services/HorizontalLineageLayout.cs) 已能以 `allowSkippedGenerations: true` 处理显式跨列正交连接，既有 [测试](../PuJiang.Tests/HorizontalLineageLayoutTests.cs) 与旧工作台可供复用；它目前限定每个子节点一条父边，不等于完成复杂继嗣关系。当前 [V1 画布](../ZupuPaiBan/Views/V1FirstRootWindow.cs)按父位置推导相邻列，尚未使用显式跨代；当前空节点路径会保存真实 Person，属于待修正的实现差异。

建议先选用**已明确的同谱、单父位置关系和明确世代**作为最小直连数据形态：从既有持久事实只读投影人物、位置、关系与显式世代，评估复用既有布局输出跨列正交路径；不引入新的关系类型或从画线反推事实。真实用户如何建立跨代承嗣/承祧、如何表示复杂多位置，不在此处假定；若现有 V1 无可用写入入口，可先用新建隔离测试样本构造明确事实进行投影验证，不能将测试构造当作正式编修能力。

## 任务与依赖（待批准）

1. 在 Application Command、领域校验和工作台入口统一落实姓名必填与取消不创建，调整“空节点”入口；保留尚未提交的草稿和失败提示。先核对所有首节点、子女及配偶等路径，兄弟姐妹以实际已接入口为准，不借机新增功能。
2. 核查当前模型是否能表达选定的明确世代及关系；若不能，先确定最小可行的数据边界，不能补造承嗣/承祧规则。建立全新隔离样本，按事实生成投影；布局以明确世代计算，不覆盖业务事实。
3. 将可复用的跨代布局接入现有画布，维持节点焦点、交互、既有排序；仅接通经确认的简单投影，不以跨代布局声称复杂关系已完成。
4. 增加必要的单元、隔离数据库和工作台测试，执行 Release 构建、日常测试及相关 UI 验证；以独立虚构样本协助用户验收，记录实际范围。

## 验收矩阵（尚未执行）

| 项目 | 验收条件 |
|---|---|
| 姓名与取消 | 各已有新增人物入口在姓名空白或仅空格时不保存，主线仅有预填姓氏也不视为已输入名字；取消无人物、关系、位置或统计副作用；有效姓名正常保存并可编辑，身份稳定。 |
| 隔离直连 | 使用有明确关系、位置和显式世代的同谱虚构样本，例如第 1 世与第 8 世；画布跨列直连且接到人物框，未产生中间人物或位置，不改变已保存世代和关系。 |
| 事实与统计 | 连线前后 Person、Placement、Relationship 数量和身份不因布局增加；统计只计真实人物；不依赖坐标或姓名猜测亲属。 |
| 保存与重读 | 涉及的正常业务写入经命令与事务提交；失败回滚并保留输入；隔离库关闭重开后事实及跨代显示一致。读取和布局本身不写入事实。 |
| 体验回归 | 既有三栏、焦点、普通子女、配偶排序及默认生母不回归；通过自动化和独立样本人工验收分别记录。 |
| 异常 | 世代缺失、冲突或当前布局无法表达时不得猜测或改写；具体提示及处理依有效契约，未确认的复杂情况先暂停确认。 |

## 尚待确认或设计

- 承嗣、祧继关系的具体创建交互、关系表达及跨代/多位置范围，不能由直接画线推断。
- 世代缺失、冲突或非递增的具体操作提示与修复，及现有布局一子多边能力不足时的展示；按 D-026、D-028 不静默猜测。
- 首批是否包含用户可操作的跨代关系建立入口，还是先验证明确事实的只读跨代显示，须在实施授权中明确；隔离样本构造不构成正式入口。
